What is TetalBot?

TetalBot is an AI-assisted Discord bot built to help moderators manage their servers through natural-language requests. It can inspect server information, find and review message context, handle moderation tasks, and manage supported Discord features. Actions that modify the server use permission checks and confirmation controls, keeping moderators in control of what gets executed.
